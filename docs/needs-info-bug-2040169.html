Continuous memory growth on Twitch when autoplay is blocked

Bug description (excerpt)

When autoplay for audio and video is blocked in Firefox settings, opening a Twitch VOD in a background tab can cause the tab's memory usage to continuously increase while the video remains paused. The memory usage only stops increasing if the video starts playing or the user switches to another tab. This appears to specifically happen while the paused Twitch VOD tab remains focused and inactive. STR: (1) In Firefox settings, set autoplay to block both audio and video. (2) Open any Twitch VOD in a new background tab (e.g. https://www.twitch.tv/videos/1637159661). (3) Switch to that tab. (4) Do not click anywhere on the page. (5) Keep the video paused and remain on the tab. (6) Observe the tab's memory usage in about:processes or system task manager.

Thanks for the report and the profile + memory report attachment. To diagnose this we still need a bit more data.

Analysis

The profile you shared (https://share.firefox.dev/4wAwdBm) was captured with a generic preset, so it doesn't include the media-specific threads we need (MediaDecoderStateMachine, MediaSupervisor, MediaPDecoder, AudioSink, cubeb). What it does show is continuous CSS animations / SMIL animations / display-list rebuilds on the Twitch tab while the video is paused — that is page-driven work, not necessarily a media bug. The memory report is a single snapshot, which doesn't show what's actually growing over time.

Next Steps

  • Please attach the contents of about:support (Help → More troubleshooting information → Copy text to clipboard).
  • Capture two about:memory reports, gzipped, and attach both: one right after opening the paused Twitch VOD tab, and a second one after several minutes of observed growth (without playing or switching tabs). Use the "Measure and save…" button on about:memory so we can diff them.
  • Please capture a media log: follow the instruction video to capture one using about:logging with the "media" preset. Start the log, reproduce the issue (keep the tab focused on the paused VOD for a few minutes), then stop the log and attach it here.
  • Does the issue still reproduce in Private Browsing mode and with all extensions disabled (Troubleshoot Mode)?
  • Does it reproduce on a regular Twitch live channel page, or only on VODs?

If you have any privacy concerns about sharing the log publicly, you can email it to media-alerts@mozilla.com instead.

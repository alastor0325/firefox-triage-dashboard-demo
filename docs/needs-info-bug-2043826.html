Bug description (excerpt)

Long-running session leak in the RDD (Remote Data Decoder) process. Not triggered by a single discrete action; accumulates over many hours of normal browsing involving media content. After ~45h uptime, RDD process working set grew to ~24 GB while about:processes and about:memory both report only ~80 MB for the same PID. The ~24 GB delta between Working Set and Private/PageFile is the signature of shared-memory mappings owned by the counterparty (the GPU process) but charged to the RDD process's working set. Terminating only the RDD process immediately released ~24 GB to the OS.
